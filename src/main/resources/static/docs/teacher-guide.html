៧.១. ការកត់ត្រាវត្តមានសិស្ស (Attendance)

  • ✔️ វត្តមាន (Present)៖ សិស្សចូលរៀនពេញម៉ោង (លំនាំដើមត្រូវបានធីកជាស្រេច)។
  • 📋 ច្បាប់ (1ច / Permission)៖ សិស្សមានលិខិតសុំច្បាប់ត្រឹមត្រូវ។
  • ❌ គ្មានច្បាប់ (1គ / Absent)៖ សិស្សអវត្តមានដោយគ្មានមូលហេតុ។

  • កំណត់ពិន្ទុពេញ (⚙️)៖ គ្រូអាចកំណត់ទម្ងន់ពិន្ទុពេញតាមមុខវិជ្ជា និងថ្នាក់រៀននីមួយៗ (ឧទាហរណ៍៖ ៧០/១៥/១៥ ឬ ១០០/០/០)។
  • ចំណាត់ថ្នាក់ និងនិទ្ទេសស្វ័យប្រវត្តិ៖ ប្រព័ន្ធបូកសរុបពិន្ទុ គណនាភាគរយ ចេញនិទ្ទេស A-F និងកំណត់ចំណាត់ថ្នាក់លេខ ១, ២, ៣... ដោយស្វ័យប្រវត្តិ។

នៅដំណាច់ខែ គ្រូអាចចូលទំព័រ «របាយការណ៍» -> ជ្រើសរើសថ្នាក់ និងខែ -> ចុច «បោះពុម្ពរបាយការណ៍ (Print 🖨️)» ដើម្បីព្រីនជាក្រដាស A4 ឬ Save as PDF យ៉ាងស្អាត ដោយប្រព័ន្ធលាក់ Sidebar និងប៊ូតុងចុចដោយស្វ័យប្រវត្តិ។

១៤.១. ការគ្រប់គ្រងគណនីគ្រូបង្រៀនសម្រាប់ Admin

គណនី ROLE_ADMIN អាចចូលទៅកាន់ /admin/accounts ដើម្បីបង្កើតគណនីគ្រូថ្មី កំណត់ពាក្យសម្ងាត់ឡើងវិញ (Reset Password) ឬបើក/ផ្អាកគណនី (Toggle Status) បានយ៉ាងងាយស្រួល។

១៥.១. ទំនាក់ទំនងជំនួយបច្ចេកទេស និងសុវត្ថិភាព
